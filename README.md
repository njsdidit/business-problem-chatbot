# 💼 Business Problem Solver Chatbot

A simple AI-powered chatbot that helps solve real-time business problems.

Built with **Streamlit** + OpenAI-compatible API (works with OpenAI, Grok/xAI, etc.).

---

## Features

- Practical advice for business issues (operations, sales, customers, inventory, productivity, etc.)
- Clean and simple chat interface
- Easy to deploy online for free
